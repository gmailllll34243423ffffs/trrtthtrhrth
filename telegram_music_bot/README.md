# 🎵 Telegram Music Dating Bot

Бот знакомств по музыкальному вкусу в стиле Дайвинчика и Бибинто на **aiogram 3.x** и **aiosqlite**.

## ✨ Особенности
1. **Регистрация в 4 раздельных сообщения:**
   * 1: Город
   * 2: Возраст
   * 3: Имя
   * 4: Любимые песни (до 3 треков)
2. **Умный фильтр анкет:**
   * Тот же город
   * Разброс по возрасту — максимум $\pm 1$ год
3. **Кнопки оценки:**
   * `👍` — Лайк
   * `👎` — Дизлайк
   * `📧` — Валентинка (считается как лайк + персональное сообщение)
   * `💤` — Режим сна (скрывает анкету из поиска)
4. **Мгновенные уведомления:**
   * Когда кто-то оценивает песню пользователя, ему сразу приходит:
     *«🔔 Кому-то понравилась твоя песня! Заканчивай оценивать и посмотри кто там 👀»*
5. **Взаимный мэтч:**
   * При взаимной симпатии бот сразу присылает контакты обоих пользователей.

---

## 🚀 Запуск на компьютере (Windows Desktop)

1. Убедись, что установлен [Python 3.10+](https://www.python.org/downloads/) (при установке обязательно поставь галочку **«Add python.exe to PATH»**).
2. Запусти файл **`start_bot.bat`** двойным кликом.
3. При первом запуске консоль сама попросит ввести токен от **@BotFather** и автоматически сохранит его в файл `.env`.

## ☁️ Запуск на GitHub + Railway (24/7 в облаке)

### Шаг 1: Загрузка на GitHub
1. Создай новый репозиторий на [github.com/new](https://github.com/new).
2. В папке с проектом выполни команды:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_ЛОГИН/ТВОЙ_РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```

### Шаг 2: Запуск на Railway
1. Перейди на **[railway.app](https://railway.app)** и войди через GitHub.
2. Нажми **New Project** ➔ **Deploy from GitHub repo**.
3. Выбери свой репозиторий с ботом.
4. В настройках проекта перейди во вкладку **Variables** и добавь переменную:
   * Имя: `BOT_TOKEN`
   * Значение: токен от `@BotFather`
5. Railway сам установит `requirements.txt`, прочитает `Procfile` и запустит бота круглосуточно.
